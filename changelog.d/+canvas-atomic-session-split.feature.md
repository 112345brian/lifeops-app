Long assignments no longer get split into duration-based "(1/2)"/"(2/2)" halves of the same generic phase. Instead, the number of real sessions needed is computed up front from total estimated effort (ceil(total_minutes / 80)), and that many distinct, content-aware session names are requested directly (e.g. "Rewrite Introduction & Methods" / "Rewrite Results & Discussion" instead of "Rewrite & Expand (1/2)" / "(2/2)"), falling back to a generic but still distinct per-atype name list when no content-aware labels are available.
