Multi-phase Canvas assignments (e.g. "Setup & Data Exploration" / "Analysis & Visualization" / "Write-Up") now get content-aware phase names read from the assignment's actual instructions via the LLM (e.g. "Pull NYC Open Data" / "Clean & Explore" / "Write Findings") instead of the same generic template for every assignment, falling back to the generic names whenever the description is empty or the call fails. Phase names are cached per assignment so they stay stable across syncs.
