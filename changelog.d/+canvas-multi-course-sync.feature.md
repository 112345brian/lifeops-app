Canvas sync now supports multiple courses at once (`CANVAS_COURSES` env var), each with its own FlowSavvy list and its own dedup log keyed by Canvas course id — which also gives a clean per-semester boundary, since a new semester's course id naturally starts a fresh log. Every created task's notes now carry a `[canvas-ref: ...]` marker back to the source Canvas assignment (or a content hash for LLM-extracted readings), used as an exact-match dedup check alongside the existing fuzzy title match.

Long assignment names are now shortened for the task title (e.g. "Predictive Policing Case Study/Evaluation Paper" → "Policing Paper") instead of overflowing, with the shortened name cached per assignment so it stays stable across syncs. Reading tasks now include the full citation (author, book/chapter, page locator, and a direct link when Canvas provides one) plus a `- [ ] Downloaded` checkbox in their notes.
