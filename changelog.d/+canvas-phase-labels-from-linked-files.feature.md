Content-aware phase names now also pull from any linked text-based file (a `.qmd`/`.py`/`.md` problem set) referenced in an assignment's description, not just the description text itself — which is often pure submission boilerplate ("answer the questions, render, submit") with the real questions living in an attachment. The phase-naming prompt also now explicitly excludes generic environment/tooling setup ("install this software") from phase names, since that's not the assignment's actual academic work.
