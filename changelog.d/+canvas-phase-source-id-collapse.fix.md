Fixed multi-phase Canvas assignments (e.g. "Outline" / "Draft" / "Revise") silently collapsing down to only their first phase — every phase of one assignment shared the same dedup id, so the exact-id check treated phase 2+ as already-created the instant phase 1 was. Each phase now gets its own id. Also fixed two distinct assignments whose LLM-shortened titles happen to look alike (e.g. an "Initial Proposal" and a "Final Proposal") getting fuzzy-merged into one despite having different, known-good Canvas ids.
