Assignments synced before their Canvas description was written (common, since a course's whole semester is often visible well before each assignment's real instructions exist) got generic phase names permanently — the tasks were never revisited once created. The sync now rechecks not-yet-content-aware assignments every run and renames their already-created phase tasks in place once a real description shows up, without disturbing existing dependencies (blockedByIds are resolved by id at creation, not by title).
