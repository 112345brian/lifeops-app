Canvas's `canvas_session` cookie is session-only, so Chromium was silently dropping the login on every relaunch of the persistent profile instead of reloading it from disk. Manual and automated re-login now capture the live cookie jar via a CDP-attached snapshot (`capture_live_session`) and re-inject it on each new context, and the login probe hits the JSON API directly instead of navigating a page (avoiding a false-negative Cloudflare redirect on stale sessions).
