Added a native Jetpack Compose home app for Android, replacing `PanelActivity`'s WebView as the app's launcher. A single `MainActivity` hosts a Compose Navigation graph with Today (status badge, briefing headline, today's events, next tasks with complete actions, and quick actions for run catchup/log gym/skip gym/block today/block tomorrow/force refresh/open full panel), Attention (renders `attention_reasons` with domain, severity, title, due time, and recommended action instead of just the widget's glyph), Recurring (a routine list/editor with a basic-fields view and a raw-text advanced view for the LifeScript constraint string), History, and System (connection status, last sync times, FCM token registration, background-gate status) screens. `PanelActivity`'s WebView is kept, unmodified, as a secondary "web panel" fallback reachable from System. `SettingsActivity` stays its own Activity (reachable from System) rather than a nav-graph screen, to avoid duplicating its existing token/permission/FCM-registration logic. `AttentionReason` gained `title`/`recommendedAction`/`due` fields (previously widget-only domain/severity) so the Attention screen has real content to render.
