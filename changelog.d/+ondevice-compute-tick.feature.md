Added `LifeOpsComputeWorker`, the first real on-device compute tick: it fetches tasks/events from FlowSavvy, persists them to the local Room database, runs the gym/social/meal/deadline-risk engines against real history, and feeds the results into the deterministic attention-state model so the widget's status badge and next-tasks list are computed on the phone instead of parsed from the home server's pre-built JSON. The old `NextTasksRefreshWorker` HTTP fetch of `/api/next-tasks`/`/api/briefing` is removed. Chore's next-occurrence task creation and YNAB's auto-categorize/approve/cover actions remain server-side follow-up work (they need write-capable FlowSavvy/YNAB calls this pass doesn't add).
