The on-device compute tick now runs the real gym scheduler itself: it books gym sessions and wind-down blocks on the phone, taking blocked days, upcoming deadline load, and existing calendar events into account, and it re-reads what's already scheduled each cycle so a session already booked is never booked twice. This closes the last "read-only, not write-capable" gap called out in the on-device compute tick's own rollout notes for gym scheduling.
