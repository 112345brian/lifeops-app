A high-effort review of the on-device compute tick caught and fixed several real bugs before the migration shipped: `FlowSavvyClient`'s asymmetric retry policy silently didn't apply to a connection failure during a write's body upload; a failed task completion in the Today app reported false success with no way to un-check the checkbox; repeated manual refresh/quick-action taps could race the periodic tick and clobber each other's widget state; the new Room database had no backup/device-transfer exclusion (unlike the encrypted token file); and two "open web panel" buttons loaded the panel unauthenticated. All five are fixed, with regression tests.
