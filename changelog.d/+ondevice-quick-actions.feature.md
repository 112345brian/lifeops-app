The Today screen's quick actions (log gym, skip gym, block today/tomorrow, run catchup) now run fully on-device instead of calling the home server's Actions API (`/api/gym/log`, `/api/gym/skip`, `/api/schedule/block-day`, `/api/domains/{name}/run`). Gym log/skip write directly to the local Room history and immediately recompute the gym ring; block-day persists a new `BlockedDayEntity` and re-runs the gym scheduling engine against it, surfacing any resulting floor-risk alert; run catchup/force refresh are now the same action. No server-HTTP fallback remains for these 4 actions.
