The new "Recurring" tab started empty on every install, even though the app has always been running gym/partner/friends/meal cadences under the hood — the old Python backend never persisted those as data, just recomputed them from hardcoded defaults every run, so there was nothing to migrate. The on-device `routines` table is now seeded with those same four defaults (matching `routine_store.py`'s `_DEFAULTS` exactly) the first time the Recurring tab loads, without touching any routine you've already edited.
