Added "LifeOps Strip Tall," a 4x2 companion to "LifeOps Strip": the same weather/gym/discretionary-spending row, plus a second row showing the next upcoming non-task calendar event. Both presets now share one responsive layout that shows or hides the second row purely based on the widget's actual placed height, so a plain Strip dragged taller (or Strip Tall dragged shorter) behaves the same way. The Strip preset's default content was also narrowed to exactly weather/gym/money (previously it borrowed the Combo widget's generic priority-ordered section list), with weather rendered at double the width of the other two cells.
